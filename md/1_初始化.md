1. 使用uv-fastapi技能初始化项目结构

2. 整体项目目录不使用技能中推荐，使用如下：
````
当前目录/
├── main.py                    # FastAPI 入口（极薄）
├── config.py                  # 配置
├── deps.py                    # 依赖注入
├── api/                       # ★ 纯路由层：只做协议处理（请求校验 + SSE 包装）
│   └── v1/
│       ├── health.py            # /chat 接口（薄，只做 SSE 流式转发）
├── services/                  # ★ 业务服务层：编排逻辑
├── agent/                     # ★ Agent 核心层（与 Web 解耦，独立可测）
│   ├── main.py
├── shared/                    # 共享类型与协议
├── alembic/                   # 数据库迁移
├── tests/
├── scripts/
└── pyproject.toml
````
- 注意点
仅搭建一个基础框架，不做任何业务逻辑处理。
